# 即刻 — 短动态

即刻是开发过程记录 + 演示，语气轻松真实，不要官方通稿。发布时配截图或 GIF。

## 动态 1 · 首发

```
把自己写的 AI Agent 安全控制平面开源了。

起因很简单：agent 自己在我机器上跑命令、读写文件，我却看不清它到底做了
什么，也没法在危险操作前拦住。于是做了个透明代理，能实时看调用图谱、
做策略审批、沙箱执行和审计，本地优先，数据不出本机。

单个 Go 二进制，MIT，欢迎来玩👇（配演示 GIF）
```

## 动态 2 · 开发过程

```
做这个项目最有意思的一个 bug：Go 的 json.Marshal 会把尖括号转义，
结果提示注入里的 </system> 特征全漏报了。后来在扫描前统一把转义还原，
才把召回拉回来。安全工具的检测链路里，这种小地方真的很容易踩。
```

## 动态 3 · 理念

```
我越来越觉得 agent 安全应该「先观察、后管控」。一上来就强拦截，误伤
正常流程没人敢用；先只记录、建立行为基线，等看清楚了再上策略，接入
阻力小很多。
```

## 动态 4 · 互动

```
你们用 agent 的时候最担心它干什么？跑命令、发外网请求，还是乱读文件？
我在想下一个版本优先补哪块，评论区告诉我。
```
